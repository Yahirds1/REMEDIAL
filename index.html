Proceso de ETL

ETL son las siglas de Extraer, Transformar y Cargar. Es el camino que siguen los datos desde su origen hasta quedar listos para analizarse.

Extract (extraer)Leer los datos de su origen: un CSV de ventas, una base de datos o una API.
Transform (transformar)Limpiar y ordenar: quitar duplicados, rellenar vacíos, corregir tipos y calcular columnas nuevas.
Load (cargar)Guardar el resultado limpio en su destino: un archivo, una base de datos o un dashboard.
import pandas as pd

# E: extraer
df = pd.read_csv("ventas_farmacia.csv")

# T: transformar
df = df.drop_duplicates()
df["Precio"] = df["Precio"].fillna(df["Precio"].mean())
df["Producto"] = df["Producto"].str.strip().str.title()
df["Ingresos"] = df["Precio"] * df["Unidades_Vendidas"]

# L: cargar
df.to_csv("ventas_limpias.csv", index=False)

Árboles de decisión

Un árbol de decisión clasifica con una serie de preguntas de sí o no. Cada pregunta divide los datos hasta llegar a una respuesta final. Ejemplo: decidir si un producto conviene tener siempre en stock.

  • ¿Se venden más de 80 unidades al mes?
    • Sí → Mantener stock alto
    • No → ¿Se vende más de 40 unidades?
      • Sí → Stock medio y revisar cada mes
      • No → Pedir solo bajo demanda
from sklearn.tree import DecisionTreeClassifier, plot_tree

arbol = DecisionTreeClassifier(max_depth=2, random_state=42)
arbol.fit(X, y)
plot_tree(arbol, feature_names=["Unidades_Vendidas"], filled=True)
